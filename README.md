# Cinemaths

Crie a aplicação web CineMatch – Recomendador de Filmes e Séries com base no documento Registro_de_Prompts_CineMatch.docx em anexo, incluindo o sistema de recomendações por preferências, favoritos, histórico, alternância de tema claro/escuro, busca, filtros, avaliações, estatísticas e integração com API de filmes (como TMDB) para catálogo dinâmico.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://cinemaths.lovable.app
